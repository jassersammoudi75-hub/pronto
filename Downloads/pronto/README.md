# PRONTO – منصة توصيل (عميل / تاجر / مندوب / أدمن)

Next.js 14 (App Router) + TypeScript + Tailwind + PostgreSQL/Prisma + NextAuth. واجهة عربية RTL بخط Cairo.

## التشغيل
```bash
docker compose up -d db          # أو استخدم أي PostgreSQL وعدّل DATABASE_URL
cp .env.example .env             # غيّر NEXTAUTH_SECRET
npm install
npm run setup                    # prisma db push + بيانات تجريبية
npm run dev                      # http://localhost:3000
```

## حسابات التجربة
كلمة المرور لكل الحسابات `password123` — أو الدخول برقم الهاتف مع OTP التجريبي `123456`.

| الدور | البريد | الهاتف |
|---|---|---|
| أدمن | admin@pronto.test | +10000000001 |
| عميل | customer@pronto.test | +10000000002 |
| تاجر | merchant@pronto.test | +10000000003 |
| مندوب | courier@pronto.test | +10000000004 |
| تاجر قيد المراجعة | merchant2@pronto.test | +10000000005 |
| مندوب قيد المراجعة | courier2@pronto.test | +10000000006 |

## سيناريو كامل
1. **عميل**: أضف منتجات من متجر ← السلة ← أكّد الطلب ← صفحة التتبع.
2. **تاجر**: "قبول الطلب" ثم "جاهز للاستلام" (وإدارة المنتجات: إضافة/تعديل السعر/حذف).
3. **مندوب**: فعّل الاستقبال ← "قبول التوصيل" ← "تم الاستلام" ← "تم التسليم".
4. **أدمن**: وافق على التاجر/المندوب قيد المراجعة وراجع الإحصائيات.

## التحقق من عزل الأدوار (Phase 6)
- بدون تسجيل دخول: `/merchant` و`/courier` و`/admin` و`/checkout` تحوّل إلى `/login`.
- عميل يفتح `/admin` ← يعود للرئيسية. تاجر يفتح `/courier` ← يعود للرئيسية.
- حسابات `*2@pronto.test` تذهب إلى `/pending` ولا تظهر متاجرها للعملاء حتى الموافقة.
- الـ API يتحقق من الدور والملكية في الخادم (تاجر لا يعدّل منتجات غيره، مندوب لا يغيّر طلب مندوب آخر، والانتقالات مرتبة).

## ما هو تجريبي
- **OTP**: رمز ثابت من `DEV_OTP`؛ استبدله بمزوّد SMS (مثل Twilio) في `lib/auth.ts`.
- **الدفع**: خيار "بطاقة" محاكاة؛ أضف Stripe Checkout/PaymentIntent داخل `app/api/orders/route.ts`.
- **الخريطة**: Leaflet بإحداثيات وهمية وحركة مندوب محاكاة؛ الحالة نفسها تُجلب فعلياً من قاعدة البيانات كل 4 ثوانٍ (بدل WebSockets).
- **المكوّنات**: Tailwind مباشرة؛ يمكن تبديلها بمكوّنات shadcn/ui لاحقاً. العملة تُضبط في `lib/utils.ts`.
